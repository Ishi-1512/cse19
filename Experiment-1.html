Web Design Fundamentals: Semester 1 Curriculum

Welcome to the *Web Design Fundamentals* course. This experiment is designed to help you *master* the basic building blocks of HTML content structuring. We will cover *text formatting*, list types, and the appropriate use of *headings* for a clean, semantic document structure.

Course Objectives

  • Understand the role of HTML in **webpage structure**.
  • Correctly apply text formatting tags: Bold, Italic, and Underline.
  • Create all three primary list types: Ordered, Unordered, and Description.
  • Learn how to structure content using various heading levels.
  • Practice using **Special Characters** like © and ™.

Module Breakdown (Ordered List)

  1. HTML Basics

    Topics include:

    • Document structure and DOCTYPE
    • Headings and Paragraphs

  2. List Management

    Focuses on different ways to present grouped information.

  3. Text Formatting and Semantics

    Using strong, emphasis, and other formatting tags effectively.

Key Terminology (Description List)

HTML
The standard markup language for documents designed to be displayed in a web browser. It is the structural backbone of any webpage.
CSS
Cascading Style Sheets, used for describing the presentation of a document written in a markup language.
Curriculum
The overall content, planned program, and structure of a course.
